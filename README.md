##沧舟云 - 虚拟主机零售系统

github项目地址:https://github.com/AgFox-super/czeidc

基于 PHP 7.2 + MySQL 的虚拟主机在线订购系统：用户邮箱注册（SMTP 验证码）、在线选购方案、易支付（支付宝/微信）下单、支付后自动调用魔方财务/ep面板 API 开通主机、独立后台入口、内置简单工单系统。前台全程 AJAX 无刷新，不需要

##使用方法
将压缩包上传到服务器的网站目录下并解压
此系统支持在虚拟主机运行

##安装
上传文件并访问http://你的域名 会自动跳转到安装页面，按提示输入信息即可，并保护好后台地址

##使用
进入http://你的域名/<你的后台地址> 并输入管理员账号密码即可登录
登录后配置好支付/smtp还有魔方财务的上游地址即可
注意：**此系统非常不建议使用宝塔api进行对接，有一定的安全隐患。强烈建议自建ep面板对接，其次建议的是对接魔方财务(有一点小bug)**
